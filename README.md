## Описание
Реализация игры "Жизнь" + добавила паттерны

## Основные функции
- Управление симуляцией (Play/Pause)
- Случайная генерация поля
- Отслеживание статистики
- Регулировка скорости(прикольный курсор)
- Предустановленные паттерны через Dropdown

## Управление

### Кнопки UI
- **Play** - запустить симуляцию
- **Pause** - поставить на паузу
- **Random** - случайное заполнение
- **Clear** - очистить поле

### Паттерны через Dropdown
- Выбор из предустановленных паттернов
- **Random** - случайное заполнение
- Другие паттерны (Glider, Spaceship и т.д.)

## Статистика в реальном времени
- **Population** - количество живых клеток
- **Iterations** - количество итераций
- **Time** - время симуляции в секундах
- **State** - текущее состояние (RUNNING/PAUSED)
